# House Price Prediction Using Linear Regression

## Activity 2 – Machine Learning

### Objective
To build a Machine Learning model using Linear Regression to predict house prices based on house area.

### Dataset
- Dataset: Housing Price Prediction
- Records: 545 (before cleaning)
- Features used: Area
- Target variable: Price

### Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

### Steps Performed
1. Loaded and explored the dataset.
2. Checked missing values and duplicates.
3. Cleaned the dataset.
4. Visualized the relationship between area and price.
5. Split the data into training and testing sets.
6. Trained a Linear Regression model.
7. Generated house price predictions.
8. Evaluated the model using MAE, MSE, RMSE and R².
9. Visualized actual vs predicted prices.
10. Predicted the price of a new house.

### Model Equation
Price = Intercept + (Coefficient × Area)

### Files Included
- Activity2_House_Price_Prediction.ipynb
- Activity2_House_Price_Prediction_Report.pdf
- Activity2_Prediction_Results.csv
- Housing.csv

### Conclusion
The Linear Regression model was developed to predict house prices based on house area. Its performance was evaluated using regression metrics and visualization.
